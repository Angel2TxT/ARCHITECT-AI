# Directivas de Git
- Todos los mensajes de commit generados automáticamente deben estar en **idioma español**.
- Utiliza el formato de Conventional Commits (ejemplos: `feat:`, `fix:`, `chore:`, `refactor:`) con la descripción redactada en español.

# Skills del proyecto (`.agents/skills`)
- Antes de diseñar, modificar o implementar interfaces, componentes, animaciones o contenido visual, consulta también las skills disponibles en `.agents/skills/` y lee el archivo `SKILL.md` correspondiente a la tarea.
- Aplica las guías y reglas de las skills aplicables del proyecto junto con las skills globales.
